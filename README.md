## Project Description

A WPF (Windows Presentation Foundation) GUI application that educates South African citizens about cybersecurity threats. The chatbot uses **keyword recognition**, **random responses**, **memory recall**, and **sentiment detection** to simulate a natural, engaging conversation about topics like password safety, phishing, and online privacy.

This project builds on Part 1 (console application) by translating all requirements into a modern graphical user interface with advanced interactive features.

---

## Features

- ✅ **WPF GUI** with a modern dark theme and ASCII art header
- ✅ **Voice Greeting** on startup (WAV file)
- ✅ **User Personalisation** (asks for name and uses it in responses)
- ✅ **Keyword Recognition** (Password, Phishing, Privacy)
- ✅ **Random Responses** using `List<string>` for varied interactions
- ✅ **Conversation Flow** (follow-up queries like "tell me more")
- ✅ **Memory and Recall** (remembers user's favourite topic)
- ✅ **Sentiment Detection** (worried / curious / neutral handling)
- ✅ **Input Validation** (handles empty and invalid inputs gracefully)
- ✅ **GitHub Actions CI** (automated build on every push)
